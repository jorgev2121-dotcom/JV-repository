# 📖 BUSINESS VOCABULARY — plain-language glossary
**TRK-2026-9797 · living document · last updated 2026-09-17 by ☁️ Cloud.**
**What our terms mean, in one line each. Any seat or future model reads this to speak our language.**

---

## The business
- **Team USA Sales / CU Inspections of South Florida** — Jorge's company; property due-diligence & inspections.
- **Jorge Valdes** — owner; non-technical; uses text-to-speech; the only human in the loop.

## The system
- **Business Brain** — the company's portable memory (open files). Belongs to the company, not any AI.
- **ATLAS** — the project of reorganizing everything into a clean folder tree.
- **Seat** — one Claude window with a role. **RAMBO / Desktop (🖥️)** = the only PC hands. **Cloud (☁️)** = second reasoning seat, no PC hands. **Cowork (🤝)** = a pull-when-opened window.
- **Anchor** — a file the tooling reads by exact path, so it never moves (CLAUDE.md, .claude/skills/, TASK-REGISTER.md).
- **Heartbeat** — a timer that wakes a seat to do work unattended.
- **Remote Control** — the direct cloud↔desktop line (currently down).

## Governance
- **RED / GREEN** — GREEN = reversible, runs free. RED = irreversible/outbound/spend, needs one owner click.
- **Charter** — CLAUDE.md, the master rulebook.
- **OD- / ED-** — Owner Directive / Executive Directive (numbered, dated, binding).
- **Held / Locked / Moved / Needs Rewrite / Deprecated / Archive Candidate** — a file's migration status.
- **EXHAUST-FIRST** — try, research a workaround, try that, THEN escalate — never hand a hard task back unattempted.

## Filing & tracking
- **TRK-2026-NNNN** — a tracking number = one job/project identity. Seeded high, increments by 3.
- **OPH-2026-NNNN** — an orphan number for a document whose job isn't known yet.
- **Folio** — Miami-Dade property ID; **always 13 digits.**
- **Tax jacket / building jacket** — the county's permit-history file for a property.
- **Microfilm gap** — a period (MDC ~1961–1978) whose permits aren't digitized; permits after it may cover it.
- **#hashtag** — a category handle (many results); a TRK is an identity (one job). Both needed, never swapped.

## Paste & routing
- **PASTE-D / PASTE-C / PASTE-X** — a labeled block to paste into Desktop / Cloud / anywhere-else.
- **#sitdown board** — the shared briefing every LLM reads at session start.
