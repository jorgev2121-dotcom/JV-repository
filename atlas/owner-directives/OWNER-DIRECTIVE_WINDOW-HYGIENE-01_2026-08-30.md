# OWNER DIRECTIVE — OD-WINDOW-HYGIENE-01
**Issued by Jorge 2026-08-30 · standing directive · applies to every seat/agent (RAMBO, desktop, Cowork)**

**Directive (verbatim intent):** *"When you open a window, you should close it once we have finished
taking actions with it, or decided to go on a different route."*

## The rule
- **Any window or browser tab an agent opens, that agent closes** — the moment the action there is
  done, or the moment we abandon that route for another.
- **No orphan windows.** This is the fix for the recurring 30-windows-open clutter that makes Jorge
  unable to find the one that matters (and is why he needs pages "popped to the front").

## Limits (so cleanup never causes harm)
- **Never close a window Jorge is actively using**, or one that holds a **pending owner action**
  (a page waiting on his click, a form mid-review, a verification screen). Close only what the agent
  itself opened and has finished with.
- If unsure whether a window is still needed, **leave it and ask** — closing the wrong window is worse
  than one extra tab.
- Closing a browser tab is GREEN (reversible — reopen it). It never includes closing unsaved work
  without saving first.
