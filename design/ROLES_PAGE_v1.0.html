How a task gets its agent

  1. Chief names the job and what it touches.
  2. It starts at the lowest level that can do the job.
  3. It moves up one level only if the job needs judgment. Never two.
  4. Fable is never picked by rotation. You say yes for that.
  5. Anything risky stops and asks you first.

The 0000 lock

To lock or change any role, you type 0000 to the chief, from any device, LLM or agent. Each change gets a dated log line with who asked.

0000 is a stopper, not real security. The log is what shows misuse. This page only displays the list; typing here does nothing.
