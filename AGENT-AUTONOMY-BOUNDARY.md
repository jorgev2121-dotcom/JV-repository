# AGENT AUTONOMY BOUNDARY — what a "free" agent may decide alone, what always stops for Jorge
**Written 2026-08-26 at Jorge's request. The line that makes a free agent safe. #autonomy-boundary #JorgeValdes**

## MAY DO ALONE — GREEN (act, then report; never wait)
- **OCR** the un-processed jackets; **tag** documents; write `.SEARCH.txt`/`.TAGS.txt` sidecars.
- **Assign OPH numbers** to un-numbered docs; **propose** TRK numbers (issue only from the registry).
- **Build the search index / the one daily board** that surfaces everything.
- **Reconcile**: match orphans to jobs, spot drift (the duplicate 01-JOBS, Palmer Trust buried in staging,
  the 10 TRK-TBD defects) and **stage** the fixes.
- **Draft** — emails, invoices, call scripts, reports — held, not sent.
- **Enhance** copies of scans (never the original); count, enumerate, survey, report.
- Anything that writes only a NEW file or is backed-up + reversible.

## MUST STOP FOR JORGE — RED (park it in the daily list, never act alone)
- **Send anything outbound** — email, invoice, proposal, any money.
- **Move / rename / delete a client's ORIGINAL document** — a one-digit misfile lands in the wrong job.
- **Issue a real TRK number** or overwrite the registry.
- **Spend money, add billing, create/enter credentials, sign anything.**
- **Widen security** (open a port, disable protection).
- **Delete anything** a client might ever need (deletion is always RED).

## WHAT IT CANNOT DO AT ALL (hard limits, not policy)
- **Run as the cloud window** — this session is ephemeral; it stops when idle. The engine must be the
  desktop (while the PC is on) or a scheduler.
- **Be trusted blindly** — a free agent with no checker produces confident-wrong that *looks* done. It is
  only safe *with* a QC gate. Freedom without QC is the old failure, faster.
- **Guarantee judgment calls** — it will make mistakes; the guardrails exist to catch them, not prevent them all.

## WHAT IT WOULD TAKE (the finite gap — most already started tonight)
1. **An always-on engine** (desktop-on-a-schedule or the JOB-0079 pilot) — *the main missing piece.*
2. **A denominator per job** (X of N) so it knows when a job is done — *tonight's count started this.*
3. **A QC gate** — cloud or a second agent verifies each batch — *cloud already does this.*
4. **Park-RED + one daily approval list** — *defined in the relief plan, ratified.*
5. **This boundary, written down** — *this file.*

**So 3 of 5 are already in place. The real remaining gap is #1 — the engine that runs when Jorge is away.**
