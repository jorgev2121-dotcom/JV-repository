File integrity

Why it is built this way

One wrong character used to be able to break everything. The first launcher was one 60,000-character file (about 740 lines). Now each page is small and independent, a manifest lists the fingerprint (SHA-256) of every code file, and a check script compares them. A typo shows up as a named file, the same day, not as a mystery. Data files (reminders, programs, status) are allowed to change and are checked only for existing.
