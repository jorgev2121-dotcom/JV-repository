VTES LLM Launcher


Every AI window you run, one search away. Type an ID (LLM-07), a hashtag (#grok), a name, or a job word (files, second opinion, voice).



Every window has a fixed address. The vtes:// ones work from any link or Win+R once RAMBO installs them; the https:// ones work right now. Tabs never move or rename.




  
Hand work to another window

  
No API, no waiting on Drive. Pick who is handing off and who gets it, say what you want done, press the big button. The packet is copied; the window opens; you press Ctrl+V once.

One rule that makes this work

  
Every window runs on a subscription. API is allowed only as a thin routing bridge, and every API run is priced first and sent to you for approval. Handoffs go through the panel above or the Drive mailbox. The ID (LLM-01…08) and hashtags travel inside every file a window produces, so any later search — Drive, Gmail, OCR, 1Password, or this page — finds who did what.
