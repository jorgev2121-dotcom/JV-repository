BUS · 📬
The Drive mailbox
How every window hands off to the next

Orders go into VTES-Inbox. Proof comes out of VTES-Outbox. Any window that can read Drive already speaks this; chat-only windows join by a pasted link.

#BUS #VTES-Inbox #VTES-Outbox
Open VTES-InboxOpen VTES-Outbox

One rule that makes this work

Every window runs on a subscription — no API meter. They hand off through Google Drive, not through each other. The ID (LLM-01…08) and hashtags travel inside every file a window produces, so any later search — Drive, Gmail, OCR, 1Password, or this page — finds who did what.
