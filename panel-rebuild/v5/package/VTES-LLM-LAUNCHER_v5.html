VTES LLM Launcher

Every AI window, bot and executor role, one search away. Type an ID (LLM-07), a hashtag (#grok), a name, or a job word (files, second opinion, classify, PII).

1. Hand work to another window

Pick the kind of task and the picker chooses the cheapest lane that can do it. Change To if you disagree. Press the big button: the packet is copied and the window opens. Press Ctrl+V once.

Client personal data goes to LOCAL only. This page can check only digits: it CANNOT catch names, home addresses, email addresses, phone numbers or any identifier written in words. Do not type passwords or card numbers here.

2. LLMs: every window

LLM-01 to LLM-09, fixed IDs. Blue pool label = what it spends.

3. Executor roles: who takes work off your hands

Five lanes. Two are not Claude and do not touch the Claude Max quota. Route by what the task needs; Claude is the last resort.

4. Bots: the scheduled agents

These run by themselves on the PC. The line on each card is read from a data file the PC writes (the Windows scheduler's own report); red NO DATA means nothing has written it yet. The desktop executor (RAMBO) checks the tasks on the PC; you type nothing.

5. Queued items: one click fills the note box

Each button puts the item in the note box and chooses the right lane. Then tick the box under the note box (not needed for LOCAL) and copy the packet. Items that need your call say so in the packet and wait for your GO.
