# DD WRITE-UP TEMPLATE — the fixed format every due-diligence write-up follows
**TRK-2026-9781 (admin band) · ratified by Jorge 2026-09-13. Model deliverable: the Alec permit-history laymen's write-up.**
Pairs with the `tax-jacket` skill and the DD report standards (snip-backed working papers + ORIGINAL/ENHANCED PDFs).

## The job of the write-up
Take the working papers (scrapes, permit cards, tax jacket, microfilm — each backed by a SNIP) and turn them
into a page the **homeowner/client understands**, that says plainly, per property: **is something wrong or
not, and exactly what it is.** Data alone isn't a deliverable; the translated verdict is.

## Fixed structure (every property write-up)
1. **Why permit history matters** — one plain paragraph (permit = proof work was legal; a change with no
   permit = the owner can be forced to legalize later).
2. **Headline** — the one-line verdict, with the caveats that stop it being "all clean."
3. **Property by property** — for each: the plain-English status + the loose ends, each backed by a snip.
4. **Things that aren't permit history but the owner must hear** (licence expiry, unpaid accounts, liens).
5. **Honest coverage limits** — what the sources do and don't cover (see the microfilm gap rule below).

## THE PERMIT-CODE TRANSLATION (owner spec 2026-09-13) — this is the core skill
Permit cards are written in **county codes, not homeowner language**. The code legend — what each number
means — is on the **second page / the page BEHIND the permit application**. The write-up's job is to
**cross-reference every code into plain language, permit by permit.**

- **Procedure:** for each permit on the card, read its code, look it up on the legend page, and write it out
  as a sentence a homeowner reads.
- **Worked example (owner's own):** a reroofing shown only as code **"999"** on the card →
  **"Reroofing permit [number], dated January 11, 1964 — received Final and is in good standing."**
- **Do this for EVERY permit**, in order. The result is a plain-English list = **"the house as permitted."**
- Each translated line is backed by the snip of that permit card entry (working paper).

## PERMITS vs TAX JACKET — the comparison (always required)
Once you have "the house as permitted," **compare it against the tax jacket.** Expect differences:
- **Depending on the year, a permit may or may not have a permit number to substantiate it.** Say so per line.
- Flag anything the tax jacket / Property Appraiser shows that the permit record does NOT (an addition, extra
  sq ft, a unit) — that is the exposure to investigate.

## THE MICROFILM GAP RULE (owner spec 2026-09-13) — state it, never paper over it
**Miami-Dade County microfilm is only available for roughly 1961–1978. Outside that range there is no
microfilm — a genuine gap.** (Confirm the exact coverage years against the county when citing them.)

**When the Property Appraiser reflects an addition during a gap period with no permit/microfilm to
substantiate it, the write-up says — verbatim shape:**
> "There is a gap in microfilm for [period]. During that gap the Property Appraiser records an addition of
> approximately **[X] sq ft**. We are therefore **unable to determine whether it is legal, compliant, or was
> built without permits.** This would be **subject to a walk-through inspection with the county inspector**,
> who would verify it was built to the code of the time."

**Never round a gap off to "clean" and never round it off to "illegal."** It is *undetermined*, and the
resolution is a named next step (the county walk-through), not a guess.

## Tone
Plain words, short sentences, answer first. The homeowner should finish each property knowing: clean, loose
end, or undetermined-pending-inspection — and what to do about it.
