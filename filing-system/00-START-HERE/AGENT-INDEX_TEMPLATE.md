# AGENT-INDEX — template. Copy into every compartment root and every job capsule as `AGENT-INDEX.md` (jobs call it `00-INDEX.md`).
**#filing #constitution #template · v1 · 2026-09-30**

Fill every field. Keep it under one screen. An AI reads THIS instead of opening the folder.

- **What is here:** one plain sentence.
- **Who reads it, and when:** which windows (LLM-01..08) and for which task.
- **Do NOT read it when:** the tasks that do not need it (this line is what saves reading).
- **Identity:** TRK / OPH / folio / permit numbers, address, parties.
- **Status:** ACTIVE / INACTIVE / ARCHIVED, and the one next action.
- **Contents, one line each:** `filename — what it is — date — current or superseded`.
- **Size:** files and MB, counted on the date below.
- **Hashtags:** `#...`
- **Counted on:** date, by which window.

*Every AGENT-INDEX ends with the stamp line: `TRK-... · vN · YYYY-MM-DD · CURRENT`.*
