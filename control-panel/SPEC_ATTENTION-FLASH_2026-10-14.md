# Panel spec · Attention flashing + pending counts + agent recommendations (owner ask 2026-10-14 ~10:10 AM ET)
Owner words: "Make buttons flash with one second intervals. When they require my attention, either because I requested a pop-up for example, or system requires owner's approval. Or a blocker has stopped. And needs permission to reroute or similar. Agentic agent should be involved in any and all of these situations to provide recommendations and the ability to approve individually or as a batch. Always indicate the amount of pending approvals so I know how much work is pending to review. Indicate executed by AI agent green and yellow tested and proof provided currently active and running period as for red those require me".
1. Any tab/button whose content needs Jorge (pending approval, requested pop-up, blocker needing reroute permission, RED ask) pulses once per second (1 Hz — under the 3-per-second safety limit). Honour prefers-reduced-motion (steady red ring instead) + a "⏸ Pause flashing" switch (remembered).
2. A big counter in the header: "🔴 N waiting on you" — always visible, click opens a single "Waiting on you" list. Each tab shows its own count badge.
3. Every waiting item carries an EXEC-01 recommendation line ("Recommend: Approve — reason…") + buttons Approve · Defer · Deny · Note, and a "Approve all N recommended" batch button (asks once to confirm; RED items needing spend/credentials/outbound are listed but excluded from batch unless ticked one by one).
4. Status colours everywhere: 🟢 GREEN = executed by an AI agent, done; 🟡 YELLOW = tested with proof / active and running; 🔴 RED = needs Jorge. Legend at top.
5. Data: reads existing approvals/tasks/blockers already in the page + exec-01/RED-ASKS + the db; stays durable (db, never only in-window).
6. Money lock respected; 375px; hover tips; button-group colours; no external scripts. Test: tools/panel/test/attention-test.js.
